# OrbitFind

OrbitFind is a visual-search app that will let users enter a topic and discover a responsive wall of images from a public image API. I chose a warm cream-and-orange palette instead of the reference app's purple styling to give the interface a more editorial feel. I also used a large hero layout and a sticky navigation header so the page has a different structure from the reference. A quick-pick chip row and result-count placeholder are included now so the interface is ready for the next stage.
